# Pitch Dark for macOS Terminal

The same pure black, cyan-accent palette as the VS Code theme, as a profile for the built-in macOS Terminal app.

## Install

1. Download [`Pitch Dark.terminal`](Pitch%20Dark.terminal) and double-click it. Terminal imports the profile and opens a window with it.
2. To make it the default: **Terminal → Settings → Profiles**, select **Pitch Dark**, then click **Default**.

The profile uses the [Hack](https://sourcefoundry.org/hack/) font at 21pt (`brew install --cask font-hack`). If Hack isn't installed, Terminal falls back to its default font; you can change it under **Profiles → Text → Font**.
